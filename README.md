# 🌍 COVID-19 Forecast Analytics Dashboard

An AI-powered interactive dashboard that analyzes global COVID-19 data and predicts future cases using machine learning.

## 🚀 Live App
[COVID-19 Forecast Analytics Dashboard
](https://covid-forecast-dashboard-karthi05ai.streamlit.app/)
## Features
- Global COVID distribution map
- Country-wise analysis
- Historical case visualization
- Daily growth rate indicator
- Top 10 affected countries chart
- Animated pandemic spread map
- 30-day forecasting using Prophet
