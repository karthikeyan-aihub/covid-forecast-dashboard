# 🌍 COVID-19 Forecast Analytics Dashboard

An **AI-powered interactive analytics dashboard** that analyzes global COVID-19 data and predicts future cases using machine learning models.

The dashboard provides **visual insights, global distribution maps, and 30-day forecasts** using Facebook Prophet to understand pandemic trends.

---

## 🚀 Live Application

🔗 **Streamlit App:**  
[COVID-19 Forecast Analytics Dashboard](https://covid-forecast-dashboard-karthi05ai.streamlit.app/)
---

## 📊 Features

✔ Global COVID-19 distribution map  
✔ Country-wise COVID analysis  
✔ Historical cases visualization  
✔ Daily growth rate indicator  
✔ Top 10 most affected countries chart  
✔ Animated pandemic spread map  
✔ 30-day future case forecasting using Prophet  
✔ Interactive charts with Plotly  

---

## 🧠 Machine Learning Models

### Prophet Model
- Time series forecasting model
- Predicts future COVID-19 cases for the next **30 days**

### LSTM Model
- Deep learning based time-series prediction
- Captures long-term dependencies in pandemic trends
